# Flood Alert System 🌊

**AI-powered, street-level flood warning prototype for Nablus**  

This project was developed during a hackathon from **Dec 23 (Birzeit University)** to **Feb 8 (An-Najah University)**.

## 🚀 About

Urban floods in Nablus can happen fast, especially during heavy rain. Our **Flood Alert System** helps residents, schools, and municipalities **know which streets are safe** and plan ahead.  

---

## 💡 Features

- **AI Flood Prediction** – 12-hour forecast, flood probability, and risk levels  
- **Flutter App** – Interactive map with street risks, alternative routes, and alerts  
- **Teamwork** – Developed with my amazing teammate Yamama Sawalmeh (GitHub: [@username](https://github.com/YAS-LJD)) ❤️
